# Plot Large Datasets with Python/Dask

## Quick Start
### 1. Install Python
[Download Python](https://www.python.org/downloads/) for your operating system and install it on your computer.

### 2. Download this code

Download the code from github (PLACEHOLDER INSTRUCTIONS)

### 3. Run setup script

**Windows (`cmd`)**

Open the `large-file-tool` directory in Windows Command Prompt (or any other terminal, like in your IDE) and type the following:

```cmd
setup.bat
venv\Scripts\Activate
```

**Linux/macOS (`bash`)**

Open the `large-file-tool` directory in a terminal and type the following:

```
bash setup.sh
source venv/bin/activate
```
